About the Project

This project was developed during my second year of studying Computer Science with Artificial Intelligence at the University of Kent.

The aim was to develop a Java-based booking system as part of a collaborative software engineering project.

Throughout the project, we worked together to develop, test and integrate different features into a functioning application.

Technologies Used

* Java
* Java Swing
* SQLite
* FlatLaf
* JUnit 5
* Git and GitLab

Project Features

The application was developed to support a range of booking-related functions, including:

* Creating and managing bookings
* Amending existing bookings
* Cancelling bookings
* Payment-related functionality
* Discounts
* Location management
* Booking confirmations
* Database integration

My Contributions

My work on the project included:

* Backend development and database integration
* Implementing and working with SQLite database functionality
* Developing and improving parts of the graphical user interface
* Integrating FlatLaf for interface styling
* Supporting testing, debugging and integration
* Working collaboratively through GitLab

Team Contributions

This was a group project completed alongside Oliver and Lexi.

Although I contributed to several areas of development, I did not personally implement every feature included in the final application.

Other features and components were developed by Oliver and Lexi as part of our shared work.

The repository retains the original Git commit history to reflect the contributions made throughout development.

What I Learned

This project helped me strengthen my Java programming skills and gain more experience with database integration, user interface development and software testing.

It also gave me valuable experience working with other developers, managing code through version control and integrating different components into one application.

Acknowledgements

Developed collaboratively by Rosie Aspland, Oliver and Lexi while at the University of Kent.
